# AKW-100 · 60 Codes

**AKW-60.1** Every Keynote meets the governing code at minimum. Code compliance
is the floor, not the requirement.

**AKW-60.2** Recite a code value **only** when reciting it makes the requirement
measurable in the field. Otherwise cite the section and let the code govern.

- Recite: `A RISE OVER 1/4 IN. AND UP TO 1/2 IN. SHALL BE BEVELED, NOT STEEPER
  THAN 1:2.`: an inspector can measure this.
- Cite: `SEE ADA COMPLIANCE SHEET.`: the whole section does not fit in a note.
- Defect: `ALL TRANSITIONS TO BE ADA COMPLIANT.`: no threshold, no citation.
  This moves the entire code lookup onto the contractor and leaves you no ground
  to reject the work.

**AKW-60.3** A recited value carries the condition that makes it legal. A value
stripped of its qualifying condition becomes a permission you did not intend.

```
2C   OVER 1/2 IN. TO 3 IN.: RAMPED, NOT STEEPER THAN 1:8, IN EXISTING
     CONSTRUCTION WHERE SPACE LIMITS REQUIRE
```

ADA §405.2 permits 1:8 only in existing construction, only where space limits
prohibit 1:12, and only up to a 3 in. rise. Drop those conditions and the
Keynote permits 1:8 in new construction, which the code does not.

**AKW-60.4** Cite as `<CODE> §<SECTION>`. Example: `ADA §303`.

**AKW-60.5** Stricter than code is permitted. Looser is never permitted. Where a
Keynote is deliberately stricter, it is still stated as a requirement, not as a
preference.

**AKW-60.6** Naming the local agency is permitted where it directs a filing or
an inspection: `DOB ELECTRICAL CONTROL UNIT`. Where the Keynote does not depend
on a specific agency, write `AUTHORITY HAVING JURISDICTION`.

**AKW-60.7** A recited code value is verified by a person before the set is
issued. An agent may draft it; an agent does not confirm it. Every recited value
is flagged for that check.
