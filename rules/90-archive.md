# AKW-100 · 90 Archive

Rules withdrawn from AKW-100. A rule ID is never renumbered and never reused.
Withdrawing a rule moves it here, where a reader who meets the old ID in an old
review comment can still find out what it said.

Two ways a rule leaves:

- **Superseded**: replaced by another rule. The entry names the replacement.
- **Archived**: withdrawn with no replacement.
